## ScanMerge 1.0.0

Initial release for Apple Silicon Macs.

### Features

- Automatic alignment of EXScanS projects and turntable captures.
- Native EXScanS project export and optional merged PLY output.
- Preservation of all measured points and the original scale.
- Desktop interface with progress reporting and cancellation.
- Command-line interface for automation.
- Automatic Polish or English interface selection.

### Requirements

- Apple Silicon Mac running macOS 13 or later.
- Supported EXScanS 3.2.0.4 ARM64 installation in `/Applications/EXScanS.app`.

### Installation

Download `ScanMerge-1.0.0-macOS-arm64.zip`, extract it, and copy `ScanMerge.app` to Applications.

This release uses an ad hoc signature. It is not Developer ID signed or notarized by Apple. If macOS blocks the application, try opening it once, then go to **System Settings → Privacy & Security → Open Anyway** and confirm. See [Apple’s instructions](https://support.apple.com/guide/mac-help/mh40616/mac).
