ScanMerge 1.0.0

Requirements
Apple Silicon Mac running macOS 13 or later, with the supported EXScanS
3.2.0.4 ARM64 installation in /Applications/EXScanS.app.

Installation
Copy ScanMerge.app to Applications.

This release uses an ad hoc signature. It is not Developer ID signed or
notarized by Apple. If macOS blocks the application, try opening it once,
then choose System Settings > Privacy & Security > Open Anyway and confirm.

Usage
Select the directory containing your scans, choose an output location,
and click Align scans. Enable PLY export to also save a merged point cloud.
Open EXScanS/merged.sln_fix from the output directory in EXScanS. Keep all
accompanying project and capture files together.

The interface uses Polish when Polish is the primary system language,
and English otherwise.
